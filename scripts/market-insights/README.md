# Market hypothesis engine
Re-run as data lands: (1) export sales chunks (nuke-strategy/bt4 e*.sql -> ev.db) and event venue/timing fields (venue/all.psv; query in this README's history), (2) `python3 engine.py` (and `BACKFILL=1` to apply the Mecum venue inference), (3) `python3 macro.py` after refreshing FRED CSVs, (4) load results into market_insights with a new run_id; rows from earlier runs whose hypothesis is no longer significant+replicated get status 'stale'.
Method: residual of log hammer after cohort (make, model key, year) + month + channel + mileage band; each dimension level vs the rest within segment; trained on sales before 2024-01, replicated on 2024-01+; Benjamini-Hochberg q<0.05 on the training p-values, and holdout p<0.05 same sign = candidate.
