# Discourses

Long-form discourses on Nuke's positioning, substrate, and operating model.

## Scholarly Foundations

These works ground the discourses' core claims about mechanism/policy separation, end-to-end design, agentic tool use, mixed-initiative coordination, and the vector/volumetric substrate; all citations below were web-verified against primary sources.

- **Separation of mechanism and policy (the BYOK "laser-tag" harness)** → Nuke owns the schema, connector, checklist, and landing zone (mechanism) while callers bring compute and intent (policy), so adding a source is "config, not code" — a direct application of building an extensible kernel of mechanisms while pushing policy to the edges/callers. [levin1975policy]
- **End-to-end placement of function (landing zone owns intake; meaning computed at endpoints)** → The rhizomatic-substrate discourse stores raw testimony + embeddings at write time and computes labels only at query time ("labels are downstream queries"), with the UI as "a projection lens, not an entity profile page" — the low-level mechanism deliberately does not interpret, leaving completeness of interpretation to the application endpoints. [saltzer1984endtoend]
- **Agentic tool use as the operating model of the harness** → The repositioning discourse reduces the extraction pipeline to "5 MCP tools" and frames the system as deciding which connector to call per source — the Toolformer thesis (models learning which APIs to call, when, with what arguments, and how to fold results back) instantiated as Nuke's connector harness. [schick2023toolformer]
- **Reason-then-act loop for intake and coordination (infer → confirm → coordinate → deliver)** → The UI-substrate discourse defines the operating loop as "infer, confirm, coordinate, deliver, cut" — interleaving reasoning over what the substrate knows with external actions (asking the human to confirm what it cannot verify) to handle uncertainty and avoid hallucination, the ReAct paradigm applied to a coordination layer. [yao2022react]
- **Push-based decision support over pull-based query (The Knowing System)** → "The Knowing System" inverts the query model into a briefing model ("System observes → System analyzes → System presents → User decides"), the system deciding what is relevant while keeping the human as decider — the mixed-initiative principle of coupling automated service with human direct manipulation, scoping autonomous action to uncertainty and expected value. [horvitz1999mixedinitiative]
- **Free-text testimony as vectors; categorical labels are projections, not columns** → The substrate discourse stores unstructured testimony alongside a dense vector embedding and computes labels (worn, palimpsest, ssd_blast) as cluster membership at query time — resting on distributed dense vector word representations where semantic similarity is geometric. [mikolov2013word2vec]
- **Vocabulary drift logged as a first-class temporal phenomenon (centroid drift)** → The discourse states label centroids "drift over time as the corpus grows; that drift is logged as a first-class temporal phenomenon," claiming semantic change in the label space is measurable and lawful — directly invoking the statistical laws of semantic change from diachronic word embeddings. [hamilton2016diachronic]
- **(x,y,z) volumetric ground truth via photogrammetric reconstruction** → The substrate discourse names its only committed ground truth as an "(x,y,z) volumetric observation paired with a 0-100 condition rating" and calls for photogrammetric stitching and per-vehicle volumetric reconstruction, citing the technique that made the path from a phone-photo set to usable geometry tractable in the last two years. [kerbl2023gaussiansplatting]
