**Why the spectrum picks FLIP here:** restore pays only when provenance survives the work —
this car's mileage chain is broken and a color-change-back is never "original silver," so the
$50k+ band stays closed no matter what's spent. Flip monetizes the two things the car
genuinely has (5-speed early car, straight dry body) without paying for stories it can't tell.
Counter-example from the same curve: the $129k '79 was a 10k-mile original — that car's lane
is OWN/HOLD; a rusty-but-original silver car would be RESTORE. The spectrum is the routing
function; the appraisal engine's three-prices model (own-it / profit / full-correct) is its
formal ancestor.

   ~$9k. Shop executes the flip plan. Split priced off the scenario table so the bear case
   still beats his cash-out today: e.g. Bill gets first $9k of net hammer + 50% of the rest →
   bear $12.0k: Bill $10.5k / shop $1.5k + reimbursed costs · base $19.9k: Bill ~$13.2k /
   shop ~$4.2k · bull $25.9k: Bill ~$16.2k / shop ~$7.2k. His floor beats his ask's realistic
   net; our upside pays for the wrench. A contract, not a security.
2. **Single named capital partner.** Partner funds $12k all-in, takes first-loss, splits
   upside with shop per the same table (Ernie/semi-flip shape — deal #0 of this model).
3. **Pooled capital.** Later. Lawyer before code (securities + dealer-license surface —
   see truck-shop venture jurisdiction notes).
