# Conditioned current-rating vocabulary

A reference current rating differs from conductor resistance, operating load and protection rating. The existing `observation_properties` registry has no corresponding keyed owner in the bounded live inventory. File one OPEN `add_property` proposal `9c1ef313-f482-428e-8c66-75d38c5f3e07` through existing `schema_proposals`; retain the existing measured `schema_proposal_key_gate` as the registration owner.

The proposed numeric class key `wire_published_current_rating` uses amperes and multi cardinality with `wire_current_rating_condition_key`. Its definition requires wire class/gauge, source ambient and maximum permitted wire temperatures, installation condition, value role, explicit unknown duty/application and exact source witnesses. No flat vehicle-wide ampacity or engineering PASS is introduced. Typed condition/source admission is still required before numerical claims or a harness parameter compiler can use it.

The prototype is exact canonical document `1d90b4f3-1d6b-40dd-ac58-b5bd0d5e9607`, revision `b818670133f8faa964e6ec0a53c078a2136465d8cfa86bfa70db2c6880a4ab94`, page `5b962e61-ab64-44d3-855c-bd77c05997e9` (PDF51, printed48). Retained manufacturer bytes, selected-page visual review, public byte hashes, replay and `reference_document_evidence` qualified readback all passed. A read-only source parser extracted six footnoted heavy-wire cells with their two ambient columns; it admits no values and remains a private prototype.

Submission replay preserves review metadata and refuses changed identity/definition or a property owned elsewhere. It does not approve itself, call the gate, write a human review, create a condition table, change readers or write source/vehicle/stock rows. The SQL contract reuses the full existing source/gate fixture, tests exact replay, review metadata preservation, refusal without retained source, measured class-key registration and unchanged resistance semantics, with no numerical observations. Production registration and eventual qualified intake remain separate evidence stages.
