# Physical reports use one declared source-admission capability

The exact-head testimony guard correctly refused the initial stock helper's raw
observation insert. Existing `ingest-observation` is an edge intake and has no
callable SQL observation core; the unsigned owner/vehicle statement owners cannot
be relabeled as physical signatures. This implements the owner-authorized
database-backed physical-work scope: source and typed stock/build event commit
atomically through a narrow canonical SQL capability selected during implementation. This is a
new declared writer with runtime enforcement, not a guard exemption or a renamed
generic insertion path.

`record_account_work` admits five closed profiles only: arrival, inspection,
pull/release, physical-operation v1 and performed-work v2. Each maps to one exact
existing domain-writer signature. The authenticated, explicitly nonanonymous
actor comes from the request context. Source registry, subject type, identifier,
receipt clock and event-clock interpretation are derived. Confidence is NULL;
an attributed physical report is not a calibrated probability. The report's
statement and normalized claim come from the domain writer's validated human
request. Existing domain source/event guards continue to verify typed projection.

There is no execute grant to authenticated, anonymous or service roles. The core
runs in the authorized domain writer's owner context, checks its actual registered
signature/owner and PostgreSQL call frames, and scopes a transaction capability to
one source row. The source table guard also requires that active core frame and
capability. An arbitrary profile, direct generic intake, caller-set capability,
service impersonation, unknown outer wrapper or malformed clock/claim is refused.
Unrelated work-record users are unaffected. Existing immutable source and typed
event guards retain their correction/withdrawal semantics. The common history
guard also refuses entry into a reserved profile through UPDATE, retains canonical
reports on DELETE, and permits only coherent retirement and processing stamps.

The migration is ordered before the first stock/physical consumer. The declared
writer is registered in AGENTS Row writes and the testimony guard's sanctioned
list; the guard is not disabled, widened to arbitrary names, or given an exemption.
Focused negative contracts and the complete stock/build chain are required before
release. No owner session, actual receipt, stock, count or physical act is used in
these disposable tests.
