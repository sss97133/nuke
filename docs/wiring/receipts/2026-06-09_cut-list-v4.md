# CUT LIST v4 — AV pin collision resolved + accepted-but-missing wires landed

v3 (145 wires) had two classes of debt: (a) an A14/AV1 double-assignment surfaced by the
2026-06-09 pinout sheets, and (b) 17 wires Skylar accepted on 2026-05-14 that were locked in
`K5_WIRING_STATE.md` §1 and projected into the `*_FROM_SUBSTRATE.yaml` files but never
appended to the cut list file itself. v4 fixes both. No wires were removed; nothing destroyed.

## Change 1 — AV pin shuffle (AGENT DECISION, reversible by Skylar)

**Conflict (source: `receipts/2026-06-09_pinout-sheets-m130-pdm30.md` conflict table):**

| Pin | Cut list v3 | 2026-04-13 harness spec |
|---|---|---|
| A14 (AV1) | #4c ETB TPS1 **AND** #102 Oil Pressure (double-assigned!) | Fuel Pressure |
| A16 (AV3) | #112 Fuel Pressure | Oil Pressure |
| A17 (AV4) | #4d ETB TPS2 | TPS1 |
| A25 (AV5) | (no wire) | TPS2 |

**Rule applied: the NEWER decision wins pins.** Precedent: the 2026-05-14 high-beam floor
dimmer receipt, an agent decision made per Skylar's directive "use the correct scientific
method ... figure out on your own" — that established that the agent may resolve substrate
conflicts by rule when the evidence is clear, with the decision filed and reversible.
The ETB receipt (#4c TPS1=A14/AV1, #4d TPS2=A17/AV4, cut list v2 change log item 1) is newer
than the analog-sensor AV map in the 2026-04-13 harness spec, so **ETB keeps A14 + A17**.

**Resolution:**

| Wire | Was | Now | Why |
|---|---|---|---|
| #4c ETB TPS1 | M130:A14 (AV1) | **unchanged** | newer decision wins; note added |
| #4d ETB TPS2 | M130:A17 (AV4) | **unchanged** | newer decision wins; note added |
| #102 Oil Pressure (ECU) | M130:A14 (AV1) — collision | **M130:A25 (AV5)** | A25 is the only free AV pin per the pinout-sheet survey ("no wire in cut list v3") |
| #108 MAP | M130:A15 (AV2) | **unchanged** | no collision; harness-spec map stale; note added |
| #112 Fuel Pressure | M130:A16 (AV3) | **unchanged** | no collision; harness-spec map stale; note added |

Companion wires #102g/#102r are unaffected (they land B16/A02, not the AV pin).

**Rationale for #102 → A25 specifically:** AV2/AV3/AV4 are occupied (#108/#112/#4d); AV5/A25
is documented empty in the 2026-06-09 pinout survey. Lowest-disruption move: one wire changes
pins, zero recrimps elsewhere, harness routing unchanged (same connector).

**Reversibility:** this is an agent decision, not a Skylar decision. If Skylar prefers the
2026-04-13 harness-spec AV map instead (AV1=FPS, AV3=OPS, AV4=TPS1, AV5=TPS2), file an
amendment receipt and swap the FROM cells; nothing else in the harness changes. The
2026-04-13 harness spec's AV map is hereby marked STALE, not deleted.
