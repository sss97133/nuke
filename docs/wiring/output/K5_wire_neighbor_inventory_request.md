## How to use this with your neighbor

1. Walk through each gauge section. Ask: "Do you have any M22759/32 in [gauge]?"
2. For each spool he has, note the color and approximate footage.
3. Mark this sheet: ✓ = neighbor has enough, ½ = partial, ✗ = need to order.
4. We re-run with his inventory subtracted; only the ✗ rows go on the ProWire order.

## Color remap notes

8 wires had 3-color stripe codes (e.g. ORN/BLK/RED) that don't exist in M22759/32. Remapped to 2-color equivalents per K5_wire_spec_and_costs.md. Differentiation maintained via heat-shrink labels at both ends.
