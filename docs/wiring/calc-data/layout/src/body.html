Margins of error

Nothing here is tape-measured yet. Each end carries a margin that comes from how its spot was found. Wiring always carries slack, so the owner's working margin for laying it out is 150 to 300 mm (6 to 12 in); where a spot is known better, the tighter number is shown.

Where this page's data comes from

The page is built by a script from these files; nothing is typed into it by hand. Parts are drawn at true size in their product colour where a size has been read. A part whose size is not read yet is not drawn: it is listed under "Not drawn yet", and selecting it shows a dashed crosshair at its spot with its margin. Stations are inches behind the front axle; lateral is inches off the centreline, positive toward the driver side; height is inches above the ground. The "Ask about this part" box sends only this page's data for the selected end to Claude, on the viewer's own Claude plan; claude.ai asks for consent the first time, and no API key is involved. Notes to the build agents are saved with the end, the view, the time and who wrote them; the agents read them from the page's store.
